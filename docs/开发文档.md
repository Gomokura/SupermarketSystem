# 超市管理系统开发文档

## 一、开发环境

### 1.1 必需软件
- JDK 1.8+
- Apache Tomcat 8.5+
- Oracle Database 11g+
- Maven 3.6+
- IDE（Eclipse/IntelliJ IDEA）

### 1.2 开发工具
- 数据库管理：SQL Developer / DBeaver
- 版本控制：Git
- 接口测试：Postman

## 二、项目配置

### 2.1 数据库配置
修改 `DBUtil.java` 中的数据库连接参数：
```java
private static final String URL = "jdbc:oracle:thin:@localhost:1521:orcl";
private static final String USER = "system";
private static final String PASSWORD = "oracle";
```

### 2.2 Maven依赖
```xml
- javax.servlet-api 3.1.0
- jsp-api 2.2
- ojdbc8 19.8.0.0
```

### 2.3 Tomcat配置
- 端口：8080
- Context Path：/SupermarketSystem
- 编码：UTF-8

## 三、代码规范

### 3.1 命名规范
- 类名：大驼峰（UserDAO, ProductServlet）
- 方法名：小驼峰（searchProducts, addUser）
- 变量名：小驼峰（userId, productName）
- 常量名：全大写下划线（MAX_SIZE, DEFAULT_STATUS）
- 包名：全小写（com.supermarket.dao）

### 3.2 注释规范
- 类注释：说明类的功能和作用
- 方法注释：说明参数、返回值、功能
- 关键代码：添加行内注释

### 3.3 代码结构
```
com.supermarket
├── bean        # 实体类（JavaBean）
├── dao         # 数据访问层
├── servlet     # 控制层
├── filter      # 过滤器
└── util        # 工具类
```

## 四、核心技术实现

### 4.1 数据库连接池
使用单例模式管理数据库连接：
```java
public static Connection getConnection() throws SQLException {
    return DriverManager.getConnection(URL, USER, PASSWORD);
}
```

### 4.2 动态SQL查询
```java
StringBuilder sql = new StringBuilder("SELECT * FROM products WHERE 1=1");
if (keyword != null && !keyword.trim().isEmpty()) {
    sql.append(" AND product_name LIKE ?");
}
```

### 4.3 权限控制
使用Filter实现统一权限验证：
```java
if (session == null || session.getAttribute("user") == null) {
    response.sendRedirect("login.jsp");
    return;
}
```

### 4.4 MVC模式
- Model：JavaBean + DAO
- View：JSP页面
- Controller：Servlet

## 五、数据库操作

### 5.1 查询操作
```java
PreparedStatement stmt = conn.prepareStatement(sql);
ResultSet rs = stmt.executeQuery();
while (rs.next()) {
    // 处理结果集
}
```

### 5.2 插入操作
```java
String sql = "INSERT INTO users VALUES (seq_user.NEXTVAL,?,?,?,?,?,?,SYSDATE)";
PreparedStatement stmt = conn.prepareStatement(sql);
stmt.setString(1, username);
stmt.executeUpdate();
```

### 5.3 更新操作
```java
String sql = "UPDATE products SET product_name=?, price=? WHERE product_id=?";
PreparedStatement stmt = conn.prepareStatement(sql);
stmt.executeUpdate();
```

### 5.4 删除操作
```java
String sql = "DELETE FROM products WHERE product_id=?";
PreparedStatement stmt = conn.prepareStatement(sql);
stmt.setInt(1, productId);
stmt.executeUpdate();
```

## 九、常见问题

### 9.1 数据库连接失败
- 检查Oracle服务是否启动
- 检查连接参数是否正确
- 检查ojdbc驱动是否正确

### 9.2 中文乱码
- 设置request编码：request.setCharacterEncoding("UTF-8")
- JSP页面设置：<%@ page contentType="text/html;charset=UTF-8" %>

### 9.3 404错误
- 检查web.xml配置
- 检查URL映射
- 检查文件路径
