## 1. 订单管理

**路由：** `/admin` → 侧边栏「订单管理」  
**文件：** `frontend/src/views/admin/Orders.vue`

### 功能说明

| 功能 | 说明 |
|------|------|
| 多条件筛选 | 支持按订单号、用户ID、状态、时间范围组合筛选 |
| 订单详情 | 点击「详情」查看商品明细、收货地址、状态时间线 |
| 快递发货 | 待发货订单可填写快递公司和快递单号发货 |
| 修改收货地址 | 待发货订单可修改收件人姓名、手机、地址 |
| 分配配送员 | 为订单指派配送员，配送员接单后开始配送 |
| 强制取消 | 管理员可强制取消任意订单，需填写取消原因 |

### 使用方法

1. 进入订单管理页，顶部筛选栏可按状态、时间范围等过滤订单
2. 点击某条订单的「详情」按钮，弹窗展示完整订单信息和操作时间线
3. **发货操作**：找到状态为「待发货」的订单 → 点击「发货」→ 填写快递公司和快递单号 → 确认
4. **分配配送员**：找到「待发货」订单 → 点击「分配配送员」→ 从下拉选择在线配送员 → 确认
5. **强制取消**：点击「强制取消」→ 填写取消原因 → 确认（任意状态均可操作）

### 测试方法

```

  2. 预期：仅显示该订单

测试 2 - 发货：
  1. 找到状态「待发货」的订单，点击「发货」
  2. 填写：快递公司=顺丰速运，快递单号=SF1234567890
  3. 点击确认
  4. 预期：订单状态变为「配送中」，快递信息保存成功

测试 3 - 强制取消：
  1. 任选一条订单，点击「强制取消」
  2. 填写原因：测试取消
  3. 点击确认
  4. 预期：订单状态变为「已取消」，列表自动刷新
```

## 2. 促销管理

**路由：** `/admin` → 侧边栏「促销管理」  
**文件：** `frontend/src/views/admin/Promotions.vue`

### 功能说明

| 功能 | 说明 |
|------|------|
| Tab 分类 | 全部活动 / 满减活动 / 秒杀活动，按类型过滤展示 |
| 进行中提示 | 页面顶部展示当前 C 端正在进行的活动名称 |
| 新增满减活动 | 支持配置多条阶梯规则（满X减Y），可关联全场或指定分类 |
| 新增秒杀活动 | 填写活动名称、时间，商品配置在秒杀管理模块完成 |
| 启用/暂停 | 一键切换活动状态，立即生效 |
| 删除 | 删除活动（请确认活动已结束或无进行中订单） |

### 字段约束（重要）

| 字段 | 合法值 |
|------|--------|
| 活动类型 | `FULL_REDUCE`（满减）/ `SECKILL`（秒杀） |
| 适用范围 | `ALL`（全场）/ `CATEGORY`（指定分类） |
| 状态 | `active`（启用）/ `paused`（暂停）/ `inactive`（停用） |

### 使用方法

**新增满减活动：**
1. 点击「添加促销」→ 选择活动类型「满减」
2. 适用范围选「全场通用」或「指定分类」（指定分类需选择具体分类）
3. 在「阶梯规则」区点击「+ 添加阶梯」，填写满减金额（如：满100减15）
4. 可继续添加多条阶梯（如：满200减35）
5. 填写开始/结束时间，设置状态为「启用」，保存

**新增秒杀活动：**
1. 点击「添加促销」→ 选择活动类型「秒杀」
2. 填写活动名称、时间，保存
3. 具体秒杀商品在「秒杀活动」管理页配置

### 测试方法

```
测试 1 - 新增满减活动：

  3. 添加阶梯：满100减10，满200减25
  4. 开始时间：今天，结束时间：明天，状态：启用
  5. 保存
  6. 预期：列表新增一条，切换至「满减活动」Tab 可见阶梯规则标签

测试 2 - 启用/暂停：
  1. 找到状态为「启用」的活动，点击「暂停」
  2. 预期：状态标签变为橙色「暂停」

测试 3 - 顶部进行中提示：
  1. 确保有活动状态为 active 且时间在当前范围内
  2. 刷新页面
  3. 预期：顶部绿色提示条显示该活动名称
```

## 5. 轮播图管理

**路由：** `/admin/banners`  
**文件：** `frontend/src/views/admin/Banners.vue`

### 功能说明

| 功能 | 说明 |
|------|------|
| 轮播图列表 | 展示图片缩略图、跳转类型、排序、状态 |
| 新增轮播图 | 上传图片，配置跳转目标和排序 |

| 启用/停用 | 控制是否在首页展示 |
| 删除 | 删除轮播图 |

### 字段说明（重要）

| 字段 | 合法值 | 说明 |
|------|--------|------|
| 跳转类型 | `NONE` | 无跳转，纯展示 |
| 跳转类型 | `PRODUCT` | 跳转到商品详情，跳转目标填商品ID |

| 跳转类型 | `ACTIVITY` | 跳转到活动页，跳转目标填活动ID |
| 排序 | 0 ~ 999 | 数字越小越靠前 |

1. **新增**：点击「新增轮播图」→ 上传图片或直接填入图片 URL → 选择跳转类型

3. 跳转类型选 `PRODUCT`/`CATEGORY`/`ACTIVITY` 时，跳转目标填对应 ID
4. 排序数字越小，在首页轮播中越靠前展示
5. **启用/停用**：仅状态为 `active` 的轮播图会在 C 端首页显示

## 7. 采购管理

**路由：** `/admin/purchase-orders`（仓储进货端，需仓库管理员角色）  
**文件：** `frontend/src/views/admin/PurchaseOrders.vue`

### 功能说明

| 功能 | 说明 |
|------|------|
| 采购单列表 | 分页+状态筛选（草稿/已审批/已收货/已取消） |
| 新建采购单 | 选择供应商、预计到货日期，填写商品明细（商品/数量/单价） |
| 查看详情 | 展示采购单完整信息和商品明细 |
| 审批 | 草稿状态的采购单审批通过后进入「已审批」 |
| 确认入库 | 货物到达后填写各商品实际到货数量，确认后自动增加库存 |
| 取消 | 仅草稿状态可取消 |

### 采购单状态流转

```
新建 → 草稿(draft) → 审批 → 已审批(approved) → 确认入库 → 已收货(received)
                    ↓
                  取消 → 已取消(cancelled)
```

### 使用方法

**创建采购单：**
1. 点击「新建采购单」
2. 选择供应商（需先在「供应商管理」中录入供应商）
3. 填写预计到货日期
4. 在商品明细表格中点击「新增一行」，选择商品、填写数量和单价
5. 可继续添加多行商品
6. 点击「提交采购单」，状态为草稿

**审批和入库：**
1. 找到「草稿」状态的采购单，点击「审批」→ 状态变为「已审批」
2. 货物到达后点击「入库」
3. 在弹窗中核对并填写各商品实际到货数量（可能与采购数量有出入）
4. 点击「确认入库」→ 系统自动增加对应商品库存，状态变为「已收货」

### 测试方法

```

  - 供应商管理中已存在至少一家供应商
  - 商品管理中已存在至少一件商品

  1. 新建采购单，选择供应商，预计到货=明天
  2. 添加商品明细：商品A×10件，单价5.00元
  3. 提交，预期：状态为「草稿」

  4. 点击「审批」
  5. 预期：状态变为「已审批」

  6. 点击「入库」，实际到货数量填 8（模拟少到2件）
  7. 点击「确认入库」
  8. 预期：状态变为「已收货」，商品A库存增加8

测试 2 - 取消采购单：
  1. 新建一张采购单（不审批）
  2. 点击「取消」→ 确认
  3. 预期：状态变为「已取消」，取消后无法审批或入库

测试 3 - 状态筛选：
  1. 在状态下拉框选择「已收货」
  2. 预期：仅显示已完成入库的采购单
```

## 常见问题

**Q: 新增轮播图报 `ORA-02290` 检查约束错误？**  
A: 跳转类型必须填大写：`NONE` / `PRODUCT` / `CATEGORY` / `ACTIVITY`，不能用小写。

**Q: 促销管理页面打开报 `ORA-00904 promotion_id 无效`？**  
A: 后端 `Promotion.java` 实体类主键映射问题，确保 `@TableId(value = "ACTIVITY_ID", type = IdType.INPUT)` 已正确配置。

**Q: 新增任何数据都报 `ORA-01400 无法插入 NULL`？**  
A: Oracle 需要序列生成主键，确认 `MybatisPlusConfig.java` 已注册 `OracleKeyGenerator`，实体类有 `@KeySequence` 注解且 `IdType = INPUT`。

**Q: 采购单入库后库存没有增加？**  
A: 确认入库时实际到货数量不能为0，且后端 `/purchase/{id}/receive` 接口接收的格式为 `{ items: [{itemId, arrivedQuantity}] }`。
