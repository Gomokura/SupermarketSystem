# 超市管理系统 · 数据库设计文档

> **数据库**：Oracle XE 21c
> **用户**：`system`
> **连接串**：`localhost:1521/ORCL`
> **建表脚本**：`database/all_tables_ascii.sql`（英文注释版，兼容所有客户端）

---

## 一、概述

本系统数据库采用 **Oracle XE 21c**，共 **30+ 张表**，涵盖用户体系、商品管理、订单流程、库存管理、营销活动、收银配送六大业务域。

## 二、核心表结构

### 2.1 USERS（顾客用户）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| USER_ID | NUMBER | 主键 |
| USERNAME | VARCHAR2(50) | 用户名（手机号） |
| PASSWORD | VARCHAR2(100) | 密码（MD5） |
| NICKNAME | VARCHAR2(50) | 昵称 |
| REAL_NAME | VARCHAR2(50) | 真实姓名 |
| PHONE | VARCHAR2(20) | 手机号 |
| EMAIL | VARCHAR2(100) | 邮箱 |
| AVATAR_URL | VARCHAR2(500) | 头像地址 |
| GENDER | VARCHAR2(1) | 性别（M/F/U） |
| MEMBER_LEVEL | VARCHAR2(20) | 会员等级 |
| POINTS | NUMBER | 当前积分 |
| STATUS | VARCHAR2(10) | 状态（active/banned） |
| CREATE_TIME | TIMESTAMP | 注册时间 |

### 2.2 ADMIN_USERS（管理员/员工账号）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| ADMIN_ID | NUMBER | 主键 |
| USERNAME | VARCHAR2(50) | 登录用户名 |
| PASSWORD | VARCHAR2(100) | 密码（MD5） |
| REAL_NAME | VARCHAR2(50) | 真实姓名 |
| PHONE | VARCHAR2(20) | 手机号 |
| ROLE | VARCHAR2(20) | 角色 |
| STATUS | VARCHAR2(10) | 状态（active/inactive） |
| CREATE_TIME | TIMESTAMP | 创建时间 |

> ROLE 取值：`super_admin` / `store_manager` / `cashier` / `warehouse` / `product_staff` / `finance` / `customer_service`

### 2.3 CATEGORIES（商品分类）

| 字段名 | 类型 | 说明 |

| 字段名 | 类型 | 说明 |

## 四、关键约束与索引

- 所有表主键均使用 `NUMBER` 自增序列
- `PRODUCTS.PRICE / COST_PRICE` 均有非负约束
- `ORDERS.ORDER_NO` 有唯一索引，防止重复下单
- 外键约束确保数据参照完整性
- `USERS.PHONE`、`BRANDS.BRAND_NAME`、`SUPPLIERS.SUPPLIER_NAME` 有唯一约束
