## 五、安全测试

### 5.1 SQL 注入

- 使用 `' OR '1'='1` 等特殊字符测试所有输入框，已做参数化查询，防护通过。

### 5.2 XSS 攻击

- 在评价、商品名等处输入 `<script>alert(1)</script>`，已被转义处理，防护通过。

### 5.3 越权访问

- 普通用户尝试通过修改 URL 直接访问其他用户订单详情，被 JWT Token 校验拦截，防护通过。
- 未登录用户访问需认证接口，返回 401，防护通过。

### 5.4 JWT Token

- Token 过期后请求返回 401，前端正确跳转登录页。
- 伪造 Token 请求返回 401，防护通过。

## 七、测试结论

经过完整功能测试、性能测试和安全测试，系统功能完整，运行稳定，满足以下设计目标：

1. 六端用户角色均可正常登录使用
2. 核心业务流程（购物→下单→支付→发货→收货→评价）全链路跑通
3. 库存事务、积分事务、优惠券事务数据一致
4. 秒杀防超卖、越权防护、注入防护均有效
5. 接口响应时间符合预期，并发场景数据无异常
