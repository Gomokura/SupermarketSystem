# 超市管理系统用户手册

## 一、系统登录

### 1.1 访问系统
在浏览器中输入：http://localhost:8080/SupermarketSystem

### 1.2 登录账户
- 管理员账户：admin / admin123
- 普通用户账户：user01 / user123

### 1.3 登录说明
- 输入用户名和密码
- 点击"登录"按钮
- 系统根据角色自动跳转到对应页面

## 二、管理员功能

### 2.1 商品管理

#### 查询商品
1. 点击左侧菜单"商品管理"
2. 在搜索框输入关键字（商品名称或供应商）
3. 选择商品分类（可选）
4. 选择排序方式（可选）
5. 点击"搜索"按钮

#### 添加商品
1. 点击"添加商品"按钮
2. 填写商品信息
3. 点击"提交"保存

#### 编辑商品
1. 在商品列表中点击"编辑"按钮
2. 修改商品信息
3. 点击"保存"更新

#### 删除商品
1. 在商品列表中点击"删除"按钮
2. 确认删除操作

### 2.2 用户管理

#### 查询用户
1. 点击左侧菜单"用户管理"
2. 输入关键字（用户名或姓名）
3. 选择角色筛选（可选）
4. 选择排序方式（可选）
5. 点击"搜索"按钮

#### 添加用户
1. 点击"添加用户"按钮
2. 填写用户信息
3. 选择用户角色（管理员/普通用户）
4. 点击"提交"保存

#### 编辑用户
1. 在用户列表中点击"编辑"按钮
2. 修改用户信息和权限
3. 点击"保存"更新

### 2.3 订单管理
1. 点击左侧菜单"订单管理"
2. 查看所有订单信息
3. 可按时间、状态筛选订单

### 2.4 统计分析
1. 点击左侧菜单"统计分析"
2. 查看销售统计数据
3. 导出报表数据

## 三、普通用户功能

### 3.1 商品浏览
1. 登录后进入用户中心
2. 点击"商品浏览"
3. 查看商品信息
4. 可搜索和筛选商品

### 3.2 我的订单
1. 点击"我的订单"
2. 查看个人订单记录
3. 查看订单详情

### 3.3 个人信息
1. 点击"个人信息"
2. 查看和修改个人资料
3. 修改联系方式

## 四、查询功能说明

### 4.1 模糊查询
- 在搜索框输入关键字
- 系统自动匹配包含关键字的记录
- 支持商品名称、供应商、用户名等字段

### 4.2 条件组合查询
- 可同时使用多个查询条件
- 关键字 + 分类 + 排序
- 系统自动组合查询条件

### 4.3 结果排序
- 价格升序/降序
- 库存升序/降序
- 注册时间排序
- 用户名排序

## 五、注意事项

1. 首次使用请修改默认密码
2. 管理员谨慎删除数据
3. 定期备份数据库
4. 退出系统请点击"退出"按钮
5. 长时间未操作会自动退出登录

## 六、常见问题

### 6.1 无法登录
- 检查用户名和密码是否正确
- 确认账户状态是否为激活状态
- 联系管理员重置密码

### 6.2 权限不足
- 确认当前登录角色
- 某些功能仅管理员可用
- 联系管理员分配权限

### 6.3 数据无法保存
- 检查必填项是否完整
- 检查数据格式是否正确
- 检查网络连接是否正常
