# 超市管理系统设计文档

## 1. 数据库设计（30分）

### 1.1 数据库表结构

#### users（用户表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| user_id | NUMBER | 用户ID | 主键 |
| username | VARCHAR2(50) | 用户名 | 唯一，非空 |
| password | VARCHAR2(100) | 密码 | 非空 |
| real_name | VARCHAR2(50) | 真实姓名 | |
| role | VARCHAR2(20) | 角色 | admin/user |
| phone | VARCHAR2(20) | 电话 | |
| status | VARCHAR2(10) | 状态 | active/inactive |
| create_time | DATE | 创建时间 | 默认当前时间 |

#### categories（商品分类表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| category_id | NUMBER | 分类ID | 主键 |
| category_name | VARCHAR2(50) | 分类名称 | 非空 |
| description | VARCHAR2(200) | 描述 | |

#### products（商品表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| product_id | NUMBER | 商品ID | 主键 |
| product_name | VARCHAR2(100) | 商品名称 | 非空 |
| category_id | NUMBER | 分类ID | 外键 |
| price | NUMBER(10,2) | 价格 | 非空 |
| stock | NUMBER | 库存 | 默认0 |
| unit | VARCHAR2(20) | 单位 | |
| supplier | VARCHAR2(100) | 供应商 | |
| status | VARCHAR2(10) | 状态 | active/inactive |
| create_time | DATE | 创建时间 | 默认当前时间 |

#### orders（订单表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| order_id | NUMBER | 订单ID | 主键 |
| user_id | NUMBER | 用户ID | 外键 |
| total_amount | NUMBER(10,2) | 总金额 | |
| order_status | VARCHAR2(20) | 订单状态 | pending/completed/cancelled |
| payment_method | VARCHAR2(20) | 支付方式 | |
| order_time | DATE | 下单时间 | 默认当前时间 |

#### order_items（订单明细表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| item_id | NUMBER | 明细ID | 主键 |
| order_id | NUMBER | 订单ID | 外键 |
| product_id | NUMBER | 商品ID | 外键 |
| quantity | NUMBER | 数量 | 非空 |
| unit_price | NUMBER(10,2) | 单价 | |
| subtotal | NUMBER(10,2) | 小计 | |

#### inventory_logs（库存记录表）
| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| log_id | NUMBER | 日志ID | 主键 |
| product_id | NUMBER | 商品ID | 外键 |
| change_type | VARCHAR2(20) | 变更类型 | in/out/adjust |
| quantity | NUMBER | 数量 | |
| operator_id | NUMBER | 操作员ID | 外键 |
| remark | VARCHAR2(200) | 备注 | |
| log_time | DATE | 记录时间 | 默认当前时间 |

### 1.2 索引设计
- idx_product_name: 商品名称索引（支持快速搜索）
- idx_product_category: 商品分类索引（支持分类查询）
- idx_order_user: 订单用户索引（支持用户订单查询）
- idx_order_time: 订单时间索引（支持时间范围查询）

### 1.3 序列设计
使用Oracle序列自动生成主键ID，保证数据一致性

## 2. 系统架构设计

### 2.1 三层架构
- 表示层（View）：JSP页面
- 业务逻辑层（Controller）：Servlet
- 数据访问层（Model）：DAO + JavaBean

### 2.2 设计模式
- MVC模式：分离视图、控制器和模型
- DAO模式：封装数据库操作
- Filter模式：统一权限控制

## 3. 功能设计

### 3.1 权限管理
- 使用Filter过滤器实现统一权限控制
- Session管理用户登录状态
- 管理员和普通用户分离访问

### 3.2 查询功能
- 支持关键字模糊查询（LIKE）
- 支持多条件组合查询（AND）
- 支持结果集排序（ORDER BY）
- 动态SQL拼接实现灵活查询

### 3.3 数据操作
- 增删改查基本操作
- 事务管理保证数据一致性
- 参数化查询防止SQL注入

## 4. 界面设计
- 响应式布局
- 渐变色彩搭配
- 卡片式设计
- 表格数据展示
- 按钮交互反馈

## 5. 安全设计
- 密码存储（建议加密）
- SQL注入防护（PreparedStatement）
- 权限验证（Filter）
- Session超时控制
