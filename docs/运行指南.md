# 超市管理系统 - 运行指南

## 一、项目概述

本项目为前后端分离的超市管理系统：
- **后端**：Spring Boot + MyBatis-Plus + Oracle 数据库，端口 `8080`
- **前端**：Vue 3 + Vite + Element Plus + Pinia，端口 `3000`
- **代理**：Vite 开发服务器将 `/api` 请求代理到后端 `8080` 端口

## 三、数据库配置

### 3.1 Oracle 连接参数（已配置）

打开 `backend/src/main/resources/application.yml`，确认以下配置：

```yaml
spring:
  datasource:
    driver-class-name: oracle.jdbc.OracleDriver
    url: jdbc:oracle:thin:@localhost:1521:ORCL
    username: system
    password: Liu12345
```

> 若 Oracle 服务名不是 `ORCL`，请改为实际的服务名（SID）。

**第一步**：按顺序执行 `database` 目录下的 SQL 脚本（先建表，再导入初始数据）：

```

├── sequences.sql          -- 序列（先执行）
├── all_tables.sql        -- 建表 + 中文注释
└── all_tables_ascii.sql  -- 建表 + 英文注释（二选一）
```

> 如果 `all_tables.sql` 导入时有编码问题，改用 `all_tables_ascii.sql`。

## 七、常见问题

### Q1：前端启动报错 "Failed to scan for dependencies"

这是 Git 合并冲突标记残留导致的。请确认以下文件已清理干净：
- `frontend/src/views/user/Profile.vue`
- `frontend/src/api/index.js`

### Q2：登录时提示"用户不存在"或"密码错误"

这是数据库中密码是明文而后端需要 MD5 密文导致的。请执行"四、3.2 导入初始化数据"的 **第二步** SQL 更新语句。

### Q3：后端启动报错 "Oracle 端口连接失败"

1. 确认 Oracle 数据库服务已启动（检查 OracleServiceXXX 或 LISTENER 服务）
2. 检查 `application.yml` 中的 `url` 和端口 `1521` 是否正确
3. 确认用户名 `system` 和密码 `Liu12345` 正确

### Q4：前端页面空白或接口 404

1. 确认后端已启动（`http://localhost:8080`）
2. 确认前端已启动（`http://localhost:3000`）
3. 清除浏览器缓存后刷新

### Q5：端口被占用

- 后端端口 `8080` 被占用：修改 `application.yml` 中的 `server.port`
- 前端端口 `3000` 被占用：Vite 会自动切换到下一个可用端口，留意终端输出中的实际地址
