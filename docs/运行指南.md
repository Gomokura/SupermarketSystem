# 超市管理系统 - 运行指南

---

## 一、项目概述

| 项目 | 说明 |
|------|------|
| 后端 | Spring Boot 3.2 + MyBatis-Plus + Oracle，端口 `8080` |
| 前端 | Vue 3 + Vite + Element Plus + Pinia，端口 `3000` |
| 代理 | Vite 将 `/api` 请求转发到后端 `8080`，无需额外配置跨域 |

### 2.1 必需软件


## 三、Oracle 数据库配置

### 3.1 连接参数

打开 `backend/src/main/resources/application.yml`，确认以下配置：

```yaml
spring:
  datasource:
    driver-class-name: oracle.jdbc.OracleDriver
    url: jdbc:oracle:thin:@localhost:1521:XE
    username: system
    password: Liu12345
```

> 若 Oracle 服务名不是 `XE`，请改为实际的服务名（SID）。

### 3.2 初始化数据库

使用 SQL Developer 或 DBeaver 连接 Oracle，执行建表脚本：

```
database/
├── all_tables.sql        # 完整建表（含中文注释）
└── all_tables_ascii.sql  # 完整建表（含英文注释，二选一）
```

> 如果 `all_tables.sql` 导入时出现编码乱码，改用 `all_tables_ascii.sql`。

### 3.3 密码 MD5 更新（重要！）

建表脚本中现有账号密码为明文，后端使用 MD5 校验，首次部署必须执行以下 SQL，否则所有账号无法登录：

```sql
-- 管理员密码（admin123 / manager123 等对应 MD5）
UPDATE admin_users SET password = '0192023a7bbd73250516f069df18b500' WHERE username = 'admin';
UPDATE admin_users SET password = '0795151defba7a4b5dfa89170de46277' WHERE username = 'manager';
UPDATE admin_users SET password = 'dbb8c54ee649f8af049357a5f99cede6' WHERE username = 'cashier01';
UPDATE admin_users SET password = 'e7bca0b30b7fdb9f0ecbb7832c5f5348' WHERE username = 'warehouse01';
UPDATE admin_users SET password = '4751368fbef4cc9420716a698d0c393a' WHERE username = 'product01';
UPDATE admin_users SET password = '3df2c034f564ae53106c928b7278d1ca' WHERE username = 'service01';

-- 顾客密码（user123 对应 MD5）
UPDATE users SET password = '6ad14ba9986e3615423dfca256d04e3f' WHERE username = '13800138001';
UPDATE users SET password = '6ad14ba9986e3615423dfca256d04e3f' WHERE username = '13800138002';
UPDATE users SET password = '6ad14ba9986e3615423dfca256d04e3f' WHERE username = '13800138003';

-- 配送员密码（courier123 对应 MD5）
UPDATE delivery_persons SET password = '1ed4a8186a0606351d36115f28cc3793' WHERE phone = '13900000001';
UPDATE delivery_persons SET password = '1ed4a8186a0606351d36115f28cc3793' WHERE phone = '13900000002';
```

> 或直接执行项目中的 `database/update_passwords.sql`，结果一致。

## 四、启动后端

### 4.1 进入后端目录

```bash
cd SupermarketSystem-master/backend
```

### 4.2 编译并运行

```bash
mvn spring-boot:run
```

或打包后运行：

```bash
mvn clean package
java -jar target/supermarket-backend-1.0.0.jar
```

启动成功标志：

```
Started SupermarketApplication in X.XXX seconds
```

后端地址：`http://localhost:8080`

## 七、常见问题

### Q1：登录提示"用户不存在"或"密码错误"

原因：数据库中密码为明文，后端需要 MD5 密文。
解决：执行本文档"三、3.3 密码 MD5 更新"中的 SQL。

### Q2：后端启动报错"Oracle 连接失败"

1. 确认 Oracle 服务已启动（检查 `OracleServiceXE` 和 `OracleXETNSListener` 服务）
2. 检查 `application.yml` 中 `url` 端口 `1521` 是否正确
3. 确认用户名 `system` 和密码 `Liu12345` 正确

### Q3：前端页面空白或接口 404

1. 确认后端已启动（`http://localhost:8080`）
2. 确认前端已启动（`http://localhost:3000`）
3. 清除浏览器缓存后强制刷新（Ctrl + F5）

### Q4：端口被占用

- 后端 `8080` 被占用：修改 `application.yml` 中 `server.port`
- 前端 `3000` 被占用：Vite 会自动切换到下一个可用端口，留意终端输出的实际地址

### Q5：前端启动报错"Failed to scan for dependencies"

原因：Git 合并冲突标记残留。
解决：确认 `frontend/src/views/user/Profile.vue` 和 `frontend/src/api/index.js` 文件中无 `<<<<<<<` / `=======` / `>>>>>>>` 标记。

## 八、接口代理说明

前端 `vite.config.js` 中已配置代理，无需手动处理跨域：

```js
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

所有 `/api` 开头的请求会自动转发到后端，前端代码中接口路径只需写 `/api/xxx`，无需写完整 URL。
