## 一、Oracle XE 安装

### 1.1 下载地址

> https://www.oracle.com/database/technologies/xe-downloads.html
>
> 需要 Oracle 账号（免费注册），下载 **Oracle Database 21c Express Edition for Windows x64**。

### 1.2 安装步骤

1. 解压下载的压缩包（`OracleXE213_Win64.zip`）
2. 运行 `setup.exe`，按向导操作
   - 选择安装路径（建议默认：`C:\app\<用户名>\product\21c\`）
   - 设置数据库密码（**请牢记此密码**，后续配置需要）
   - 等待安装完成（约 10~20 分钟）
3. 安装完成后会自动启动以下服务：
   - `OracleServiceXE`：数据库主服务
   - `OracleXETNSListener`：网络监听服务

### 1.3 验证安装

打开 CMD，输入：

```bash
sqlplus system/Liu12345@localhost:1521/ORCL
```

登录成功出现 `SQL>` 即表示安装正常。

## 二、项目数据库配置

### 2.1 修改连接配置

打开 `backend/src/main/resources/application.yml`，修改以下内容：

```yaml
spring:
  datasource:
    driver-class-name: oracle.jdbc.OracleDriver
    url: jdbc:oracle:thin:@localhost:1521/ORCL
    username: system
    password: Liu12345  # 实际安装密码
```

### 2.2 导入数据库表

使用 SQL Developer 或 DBeaver 连接 Oracle，执行以下脚本：

```bash
# 如果中文乱码，使用英文版脚本
sqlplus system/Liu12345@localhost:1521/ORCL @database/all_tables_ascii.sql

# 如果不乱码，使用中文版脚本
sqlplus system/Liu12345@localhost:1521/ORCL @database/all_tables.sql
```

执行顺序：`all_tables.sql`（或 `all_tables_ascii.sql`）已包含建表、序列、初始数据的完整流程，**无需执行其他 SQL 文件**。

## 三、服务管理

### 3.1 常用服务命令

按 `Win + R`，输入 `services.msc`，找到 Oracle 相关服务：

| 服务名 | 说明 | 建议 |
|--------|------|------|
| OracleServiceXE | 数据库主服务 | 开机自启 |
| OracleXETNSListener | 网络监听（允许远程连接） | 开机自启 |

启动/停止服务：

```bash
# 启动
net start OracleServiceXE
net start OracleXETNSListener

# 停止
net stop OracleServiceXE
net stop OracleXETNSListener
```

### 3.2 监听状态检查

```bash
lsnrctl status
```

状态为 `READY` 表示监听正常。

## 四、数据备份与恢复

### 4.1 逻辑导出（expdp）

```bash
expdp system/Liu12345@localhost:1521/ORCL directory=DATA_PUMP_DIR dumpfile=supermarket_backup_%date:~0,4%%date:~5,2%%date:~8,2%.dmp logfile=backup.log
```

> 需要先在 Oracle 中创建目录对象：`CREATE DIRECTORY DATA_PUMP_DIR AS 'C:\oracle_backup';`

### 4.2 逻辑导入（impdp）

```bash
impdp system/Liu12345@localhost:1521/ORCL directory=DATA_PUMP_DIR dumpfile=supermarket_backup_20260331.dmp remap_schema=system:SYSTEM
```

关闭 Oracle 服务后，直接复制以下目录进行冷备份：

## 五、常见问题

### 5.1 Oracle 服务无法启动

**现象**：连接时报 `ORA-12541: TNS:no listener` 或 `ORA-01034: ORACLE not available`。

**排查步骤**：
1. 确认 `OracleServiceXE` 和 `OracleXETNSListener` 服务已启动
2. 在 CMD 中运行 `lsnrctl status`，确认监听状态
3. 检查 `tnsnames.ora` 文件是否包含 `XE` 条目（位于 `C:\app\<用户名>\product\21c\network\admin\`）

### 5.2 连接被拒绝（ORA-12505）

**现象**：`ORA-12505: TNS:listener does not currently know of SID given in the connect descriptor`

**解决**：检查 `application.yml` 中 SID 是否正确，Oracle XE 的 SID 固定为 `XE`。

### 5.3 密码忘记

以管理员身份运行 CMD：

```bash
sqlplus / as sysdba
ALTER USER system IDENTIFIED BY 新密码;
```

### 5.4 端口 1521 被占用

1. 查找占用进程：
   ```bash
   netstat -ano | findstr 1521
   ```
2. 结束进程或修改 Oracle 监听端口（通过 Oracle Net Configuration Assistant）

### 5.5 建表脚本执行报错

- **字符集问题**：改用 `all_tables_ascii.sql`
- **权限不足**：确认使用的是 `system` 用户（有 DBA 权限）
- **序列不存在**：确保 `all_tables.sql` 完整执行（包含 `CREATE SEQUENCE` 语句）

## 六、生产环境注意事项

1. **密码安全**：生产环境中 `application.yml` 的数据库密码不应明文存储，建议使用环境变量或密钥管理服务
2. **端口暴露**：后端 `8080` 端口仅供前端代理访问，不应直接暴露到外网
3. **CORS 配置**：生产环境建议通过 Nginx 反向代理，不依赖后端 CORS 配置
4. **日志管理**：生产环境建议配置日志轮转（logback），避免日志文件无限增长
5. **连接池**：生产环境可根据并发量调整 HikariCP 连接池大小

## 七、项目启动命令汇总

```bash
# 1. 启动 Oracle（确保服务运行中）
# （通过 services.msc 或 net start 命令）

# 2. 导入数据库
sqlplus system/Liu12345@localhost:1521/ORCL @database/all_tables_ascii.sql
sqlplus system/Liu12345@localhost:1521/ORCL @database/update_passwords.sql

# 3. 启动后端
cd backend
mvn spring-boot:run

# 4. 启动前端（新终端窗口）
cd frontend
npm install   # 首次运行
npm run dev
```
