# 超市管理系统 项目总文档

## 一、项目概述

本系统是一个基于 Java Web 的超市综合管理平台，采用经典 MVC 架构，支持管理员、普通用户、快递员三种角色，涵盖商品管理、订单管理、库存管理、配送管理、财务报表等核心业务模块。

---

## 二、技术栈

| 层次 | 技术 |
|------|------|
| 前端 | JSP + HTML + CSS + JavaScript |
| 后端 | Java 8 + Servlet 6.0 |
| 数据库 | Oracle Database XE |
| 数据访问 | 原生 JDBC + PreparedStatement |
| 构建工具 | Maven |
| 服务器 | Tomcat |
| 第三方库 | Apache POI（Excel）、Commons FileUpload、JSTL |

---

## 三、系统角色

| 角色 | 说明 |
|------|------|
| admin | 管理员，拥有全部权限 |
| user | 普通用户，可浏览商品、下单、管理地址 |
| courier | 快递员，只能查看和更新配送任务 |

---

## 四、功能模块

### 4.1 用户模块
- 登录 / 登出
- 用户注册与管理（admin）
- 修改密码、个人资料
- 积分系统、账号冻结/解冻
- 用户消费画像分析

### 4.2 商品模块
- 商品列表查询（分类、关键词搜索）
- 商品增删改（admin）
- 商品分类管理
- 价格历史记录
- 供应商管理

### 4.3 购物车 & 订单模块
- 加入购物车、修改数量、删除
- 结算（支持现金/微信/支付宝/银行卡）
- 促销折扣（满减 / 折扣）自动计算
- 订单状态跟踪（待处理 / 已完成 / 已取消）
- 订单详情查看

### 4.4 库存模块
- 入库 / 出库操作
- 库存变动日志
- 低库存预警（≤5件触发）
- 负库存检测

### 4.5 配送模块
- 配送单创建（下单后自动生成）
- 快递员分配
- 配送状态跟踪（待派送 / 已派送 / 配送中 / 已完成）
- 快递员任务列表

### 4.6 采购模块
- 采购订单创建（多商品）
- 供应商管理
- 采购审批 & 入库
- 采购成本统计

### 4.7 财务模块
- 月度营收 / 成本分析
- 分类营收占比
- 利润率计算
- 销售 Top 商品排行

### 4.8 营销模块
- 促销活动管理（折扣 / 满减）
- 活动时间段设置
- Banner 活动管理

### 4.9 系统管理
- 操作审计日志（含 IP 记录）
- 异常预警中心
- Excel 数据导入 / 导出
- 用户行为追踪（浏览 / 点击 / 购买）

## 五、数据库设计

### 5.1 核心实体关系

```
用户(USERS) ──< 订单(ORDERS) ──< 订单明细(ORDER_ITEMS) >── 商品(PRODUCTS)
用户(USERS) ──< 购物车(CART) >── 商品(PRODUCTS)
用户(USERS) ──< 收货地址(ADDRESS)
订单(ORDERS) ──1 配送单(DELIVERIES) >── 快递员(USERS[courier])
订单(ORDERS) ──1 支付记录(PAYMENT)
商品(PRODUCTS) >── 分类(CATEGORIES)
商品(PRODUCTS) ──< 库存日志(INVENTORY_LOGS)
商品(PRODUCTS) ──< 价格历史(PRICE_HISTORY)
促销(PROMOTIONS) ──< 促销商品(PROMOTION_PRODUCTS) >── 商品(PRODUCTS)
采购单(PURCHASE_ORDERS) ──< 采购明细(PURCHASE_ITEMS) >── 商品(PRODUCTS)
```

### 5.2 数据表清单

| 表名 | 说明 |
|------|------|
| USERS | 用户账号与角色 |
| PRODUCTS | 商品信息 |
| CATEGORIES | 商品分类 |
| ORDERS | 订单主表 |
| ORDER_ITEMS | 订单明细 |
| CART | 购物车 |
| ADDRESS | 收货地址 |
| PAYMENT | 支付记录 |
| DELIVERIES | 配送单 |
| INVENTORY_LOGS | 库存变动日志 |
| WAREHOUSING | 入库记录 |
| OUTBOUND | 出库记录 |
| PROMOTIONS | 促销活动 |
| PROMOTION_PRODUCTS | 促销商品关联 |
| PURCHASE_ORDERS | 采购订单 |
| PURCHASE_ITEMS | 采购明细 |
| SUPPLIERS | 供应商 |
| AUDIT_LOGS | 审计日志 |
| USER_BEHAVIOR | 用户行为记录 |
| PRICE_HISTORY | 价格历史 |
| ACTIVITIES | Banner活动 |

### 5.3 主要表字段

**USERS**
```
user_id(PK), username, password, real_name, role, phone, status, create_time
```

**PRODUCTS**
```
product_id(PK), product_name, category_id(FK), price, stock, unit, supplier, status, create_time
```

**CATEGORIES**
```
category_id(PK), category_name, description, parent_id
```

**ORDERS**
```
order_id(PK), user_id(FK), total_amount, order_status, payment_method, order_time
```

**ORDER_ITEMS**
```
item_id(PK), order_id(FK), product_id(FK), quantity, unit_price, subtotal
```

**CART**
```
cart_id(PK), user_id(FK), product_id(FK), quantity, add_time
```

**ADDRESS**
```
address_id(PK), user_id(FK), receiver, phone, detail, is_default
```

**PAYMENT**
```
payment_id(PK), order_id(FK), amount, status, pay_time
```

**DELIVERIES**
```
delivery_id(PK), order_id(FK), courier_id(FK), address, receiver, phone, status, dispatch_time, done_time
```

**INVENTORY_LOGS**
```
log_id(PK), product_id(FK), change_type, quantity, operator_id(FK), remark, log_time
```

**PROMOTIONS**
```
promotion_id(PK), promo_name, promo_type, condition_val, discount_val, start_time, end_time, status
```

**PURCHASE_ORDERS**
```
po_id(PK), supplier_id(FK), operator_id(FK), status, total_cost, create_time
```

**SUPPLIERS**
```
supplier_id(PK), supplier_name, contact, phone, status
```

**AUDIT_LOGS**
```
log_id(PK), operator_id(FK), action, target, ip, create_time
```

## 七、团队分工

### 成员A — 用户权限 + 财务报表
- 用户登录/注册/角色管理、Session、AuthFilter
- 用户消费画像、积分、账号冻结
- 财务报表（月度营收/成本/利润/分类占比）
- 审计日志

### 成员B — 商品 + 分类 + 供应商
- 商品增删改查、分类管理
- 价格历史记录
- 供应商管理
- 商品 Excel 导入/导出

### 成员C — 购物车 + 订单 + 支付
- 购物车增删改
- 下单流程（事务处理：订单+明细+出库+支付）
- 支付记录
- 用户端订单历史查看

### 成员D — 库存 + 采购
- 库存入库/出库、库存日志
- 低库存/负库存预警
- 采购订单创建、审批、入库
- 异常预警中心

### 成员E — 配送 + 促销 + 统计
- 配送单创建、快递员分配、状态跟踪
- 快递员任务页面
- 促销活动管理（折扣/满减）
- 销售统计、Top 商品排行、Banner 活动

### 工作量对比

| 成员 | Servlet数 | JSP数 | DAO数 | 复杂度 |
|------|-----------|-------|-------|--------|
| A | 3 | 5 | 4 | 高（权限+报表） |
| B | 3 | 5 | 4 | 中高 |
| C | 3 | 4 | 4 | 高（事务） |
| D | 3 | 4 | 3 | 中高 |
| E | 4 | 5 | 4 | 中高 |

## 八、协作规范

- A 第一周优先完成 `DBUtil` + `AuthFilter` + 登录，其他人才能开始联调
- 实体类（bean）各自写自己模块的，统一放 `bean/` 包
- URL 命名规范：`/admin/xxx`、`/user/xxx`、`/courier/xxx` 各自不重叠
- 用 Git 各开分支，最后 A 负责合并

---

## 九、部署说明

1. 安装 Oracle XE，按顺序执行 `database/` 下的 SQL 脚本
2. 修改 `DBUtil.java` 中数据库连接信息（默认 `system/123456`，地址 `localhost:1521:XE`）
3. 执行 `mvn clean package` 打包
4. 将 `target/SupermarketSystem.war` 部署到 Tomcat 的 `webapps/` 目录
5. 访问 `http://localhost:8080/SupermarketSystem`

**默认账号：**

| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | admin | admin123 |
| 普通用户 | user01 | user123 |
