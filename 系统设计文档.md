## 1. 项目架构概览

```
┌─────────────────────────────────────────────────────────┐
│                      前端层（Vue 3）                      │
│  顾客端  │  管理后台  │  收银端  │  仓储端  │  看板端  │  配送端  │
└──────────────────────────┬──────────────────────────────┘
                           │  HTTP / JSON（Axios）
                           ▼
┌─────────────────────────────────────────────────────────┐
│                  后端层（Spring Boot 3）                   │
│   JWT鉴权拦截器  →  Controller  →  Service  →  Mapper    │
└──────────────────────────┬──────────────────────────────┘
                           │  MyBatis-Plus / JDBC
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    数据库（Oracle）                        │
│              30张核心业务表 + Sequence主键                  │
└─────────────────────────────────────────────────────────┘
```

## 3. 六端口功能分工

| 端口 | 路由前缀 | 面向用户 | 角色标识 |
|------|---------|---------|---------|
| 顾客端（C端） | `/` | 消费者 | `ROLE_USER` |
| 管理后台（B端） | `/admin` | 超级管理员/店长/商品专员/财务/客服/仓管 | `ROLE_ADMIN` |
| 收银端 | `/cashier` | 收银员 | `ROLE_CASHIER` |
| 仓储进货端 | `/warehouse` | 仓库管理员 | `ROLE_WAREHOUSE` |
| 数据看板端 | `/dashboard` | 店长/老板 | `ROLE_MANAGER` |
| 配送员端（H5）| `/delivery` | 配送员 | `ROLE_COURIER` |

> **说明**：所有端口共用同一套后端服务，通过 JWT Token 中的 `role` 字段区分权限。

## 4. 数据库设计

> 数据库：Oracle；主键统一使用 `NUMBER` 类型 + Sequence 自增；时间字段使用 `TIMESTAMP`。

### 4.1 用户与权限类（6张表）

#### ① users — 顾客用户表
```sql
CREATE TABLE users (
    user_id       NUMBER PRIMARY KEY,
    username      VARCHAR2(50)  UNIQUE NOT NULL,   -- 手机号作为用户名
    password      VARCHAR2(100) NOT NULL,           -- BCrypt加密
    nickname      VARCHAR2(50),                     -- 昵称
    real_name     VARCHAR2(50),
    gender        CHAR(1)       DEFAULT 'U',        -- M/F/U
    birthday      DATE,
    email         VARCHAR2(100),
    avatar_url    VARCHAR2(500),                    -- 头像本地路径
    phone         VARCHAR2(20),
    member_level  VARCHAR2(20)  DEFAULT 'NORMAL',  -- NORMAL/SILVER/GOLD/DIAMOND
    points        NUMBER        DEFAULT 0,          -- 积分余额
    status        VARCHAR2(10)  DEFAULT 'active',  -- active/banned
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP,
    update_time   TIMESTAMP     DEFAULT SYSTIMESTAMP
);
CREATE SEQUENCE seq_users START WITH 1000 INCREMENT BY 1;
```

#### ② admin_users — 管理员用户表
```sql
CREATE TABLE admin_users (
    admin_id      NUMBER PRIMARY KEY,
    username      VARCHAR2(50)  UNIQUE NOT NULL,
    password      VARCHAR2(100) NOT NULL,
    real_name     VARCHAR2(50),
    role          VARCHAR2(30)  NOT NULL,   -- SUPER_ADMIN/MANAGER/PRODUCT/FINANCE/SERVICE/WAREHOUSE/CASHIER/COURIER
    status        VARCHAR2(10)  DEFAULT 'active',
    last_login    TIMESTAMP,
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP
);
CREATE SEQUENCE seq_admin_users START WITH 1 INCREMENT BY 1;

-- 初始超级管理员
INSERT INTO admin_users VALUES (seq_admin_users.NEXTVAL, 'admin', '$2a$10$加密后密码', '系统管理员', 'SUPER_ADMIN', 'active', NULL, SYSTIMESTAMP);
```

#### ③ addresses — 收货地址表
```sql
CREATE TABLE addresses (
    address_id    NUMBER PRIMARY KEY,
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    receiver_name VARCHAR2(50)  NOT NULL,
    phone         VARCHAR2(20)  NOT NULL,
    province      VARCHAR2(50)  NOT NULL,
    city          VARCHAR2(50)  NOT NULL,
    district      VARCHAR2(50)  NOT NULL,
    detail        VARCHAR2(200) NOT NULL,           -- 详细地址
    is_default    NUMBER(1)     DEFAULT 0,          -- 1=默认地址

```

#### ④ messages — 站内消息表
```sql
CREATE TABLE messages (
    message_id    NUMBER PRIMARY KEY,
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    title         VARCHAR2(100) NOT NULL,
    content       VARCHAR2(500) NOT NULL,
    msg_type      VARCHAR2(30)  DEFAULT 'SYSTEM',  -- SYSTEM/ORDER/COUPON/AFTER_SALES
    is_read       NUMBER(1)     DEFAULT 0,
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP
);
CREATE SEQUENCE seq_messages START WITH 1 INCREMENT BY 1;
```

#### ⑤ points_logs — 积分流水表
```sql
CREATE TABLE points_logs (
    log_id        NUMBER PRIMARY KEY,
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    change_amount NUMBER        NOT NULL,           -- 正=增加，负=扣减
    balance_after NUMBER        NOT NULL,           -- 变动后余额
    reason        VARCHAR2(100) NOT NULL,           -- 下单/退款/活动/管理员调整
```

#### ⑥ audit_logs — 操作审计日志表
```sql
CREATE TABLE audit_logs (

    module        VARCHAR2(50)  NOT NULL,           -- 操作模块

    target_id     NUMBER,                           -- 操作对象ID
```

### 4.3 购物与订单类（5张表）

#### ⑫ cart — 购物车表
```sql
CREATE TABLE cart (
    cart_id       NUMBER PRIMARY KEY,
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    product_id    NUMBER        NOT NULL REFERENCES products(product_id),
    quantity      NUMBER        DEFAULT 1,
    is_checked    NUMBER(1)     DEFAULT 1,          -- 是否勾选结算
    add_time      TIMESTAMP     DEFAULT SYSTIMESTAMP,
    UNIQUE (user_id, product_id)
);
CREATE SEQUENCE seq_cart START WITH 1 INCREMENT BY 1;
```

#### ⑬ orders — 订单主表
```sql
CREATE TABLE orders (
    order_id      NUMBER PRIMARY KEY,
    order_no      VARCHAR2(30)  UNIQUE NOT NULL,    -- 业务单号，如 SM202603230001
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    address_id    NUMBER        REFERENCES addresses(address_id),
    total_amount  NUMBER(12,2)  NOT NULL,           -- 商品总额
    discount_amount NUMBER(12,2) DEFAULT 0,         -- 优惠金额
    pay_amount    NUMBER(12,2)  NOT NULL,           -- 实付金额
    pay_method    VARCHAR2(20)  DEFAULT 'MOCK',     -- MOCK/CASH
    coupon_id     NUMBER,                           -- 使用的优惠券
    points_used   NUMBER        DEFAULT 0,          -- 使用积分
    status        VARCHAR2(20)  DEFAULT 'PENDING_PAY',
    -- PENDING_PAY(待支付)/PAID(已支付)/PENDING_SHIP(待发货)/
    -- SHIPPING(配送中)/COMPLETED(已完成)/CANCELLED(已取消)
    delivery_person_id NUMBER,                      -- 分配的配送员
    remark        VARCHAR2(500),
    pay_time      TIMESTAMP,
    ship_time     TIMESTAMP,
    complete_time TIMESTAMP,
    cancel_time   TIMESTAMP,
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP
);
CREATE SEQUENCE seq_orders START WITH 1 INCREMENT BY 1;
```

#### ⑭ order_items — 订单明细表
```sql
CREATE TABLE order_items (
```

```sql
    product_id    NUMBER        NOT NULL REFERENCES products(product_id),
    quantity      NUMBER        NOT NULL,
    reason        VARCHAR2(200) NOT NULL,           -- 过期/破损/其他
    operator_id   NUMBER        NOT NULL,
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP
);
CREATE SEQUENCE seq_damage_records START WITH 1 INCREMENT BY 1;
```

#### ㉚ favorites — 商品收藏表
```sql
CREATE TABLE favorites (
    fav_id        NUMBER PRIMARY KEY,
    user_id       NUMBER        NOT NULL REFERENCES users(user_id),
    product_id    NUMBER        NOT NULL REFERENCES products(product_id),
    create_time   TIMESTAMP     DEFAULT SYSTIMESTAMP,
    UNIQUE (user_id, product_id)
);
CREATE SEQUENCE seq_favorites START WITH 1 INCREMENT BY 1;
```

## 5. 统一接口规范

### 5.1 基础约定

| 项目 | 规范 |
|------|------|
| 基础URL | `http://localhost:8080/api` |
| 请求格式 | `Content-Type: application/json` |
| 认证方式 | 请求头 `Authorization: Bearer <token>` |
| 字符编码 | UTF-8 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |

### 5.2 统一响应体
```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token失效 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 5.3 分页参数（列表接口统一）
```json
// 请求参数
{
  "page": 1,        // 页码，从1开始
  "pageSize": 10    // 每页条数
}

// 响应data结构
{
  "records": [],    // 数据列表
  "total": 100,     // 总条数
  "page": 1,
  "pageSize": 10
}
```

## 8. 前端开发指引（给队员）

### 8.1 环境搭建
```bash
# 安装依赖
cd frontend
npm install

# 启动开发服务器（代理后端 localhost:8080）
npm run dev
```

### 8.2 Axios封装（已配置）
```javascript
// src/api/request.js — 已封装以下能力：
// 1. 自动在请求头添加 Authorization: Bearer <token>
// 2. 响应拦截：code != 200 自动弹出错误提示
// 3. 401 自动跳转登录页

import request from '@/api/request'

// 使用示例
const res = await request.get('/products', { params: { keyword: '可乐' } })
const res = await request.post('/orders', { cartIds: [1,2] })
```

### 8.3 路由权限守卫（已配置）
```javascript
// 路由 meta 字段说明
{
  path: '/admin',
  meta: {
    requiresAuth: true,       // 需要登录
    roles: ['SUPER_ADMIN', 'MANAGER']  // 允许的角色
  }
}
// 路由守卫会自动读取 Pinia store 中的 token 和 role 进行拦截
```

### 8.4 开发规范
- 组件使用 **Composition API（`<script setup>`）**
- 使用 **Element Plus** 现成组件，不要手写复杂UI
- 列表页统一用 `el-table` + `el-pagination`
- 表单校验使用 Element Plus Form 的 `rules`
- 所有接口调用放在 `src/api/` 对应文件中，不要在组件内直接写 axios
- 图片路径前缀统一为后端地址：`http://localhost:8080`

### 8.5 各端入口路由约定
| 端口 | 登录页 | 首页 |
|------|--------|------|
| 顾客端 | `/login` | `/` |
| 管理后台 | `/admin/login` | `/admin/dashboard` |
| 收银端 | `/cashier/login` | `/cashier` |
| 仓储端 | `/warehouse/login` | `/warehouse` |
| 数据看板 | 复用管理后台登录 | `/dashboard` |
| 配送员H5 | `/courier/login` | `/courier` |
